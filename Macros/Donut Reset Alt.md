# Donut Reset (Alt):

<img src="/Macro-Images/Donut_Reset_Alt.gif" />

### <ins>Info:</ins>
This can be used to reset your game when making donuts if you don't get the result you want and would like to reclaim your berries. This is similar to the original Donut Reset macro, except it uses the 'Travel Spots' menu to fast travel. Make sure to use the Pokécenter east of Hotel Z to make a backup save, then toggle the macro after making a donut that you want to discard.

> [!CAUTION]
> Please be aware that this macro closes the game and loads from backup data; use with caution.
