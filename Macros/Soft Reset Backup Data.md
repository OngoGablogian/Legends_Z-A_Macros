# Soft Reset Backup Data:

<img src="/Macro-Images/Soft_Reset_Backup_Data.gif" />

### <ins>Info:</ins>
This is a simple "soft reset" macro that also restores from backup save data.

> [!CAUTION]
> Please be aware that this macro closes the game and loads from backup data; use with caution.

----

### Paste Into GP2040-CE Web Configurator.
```
[{"buttonMask":4096,"duration":100000,"waitDuration":0},{"buttonMask":0,"duration":100000,"waitDuration":700000},{"buttonMask":8,"duration":100000,"waitDuration":300000},{"buttonMask":2,"duration":100000,"waitDuration":600000},{"buttonMask":2,"duration":100000,"waitDuration":900000},{"buttonMask":2,"duration":100000,"waitDuration":7500000},{"buttonMask":65545,"duration":100000,"waitDuration":0},{"buttonMask":0,"duration":100000,"waitDuration":800000},{"buttonMask":2,"duration":100000,"waitDuration":800000},{"buttonMask":2,"duration":100000,"waitDuration":800000},{"buttonMask":2,"duration":100000,"waitDuration":0},{"buttonMask":0,"duration":100000,"waitDuration":100000}]
```
