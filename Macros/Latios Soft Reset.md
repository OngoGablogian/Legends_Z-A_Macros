# Latios Soft Reset:

<img src="/Macro-Images/Latios_Soft_Reset.gif" />

### <ins>Info:</ins>
This is useful for shiny hunting Latios in [Hyperspace Lumiose](https://www.serebii.net/legendsz-a/hyperspacelumiose.shtml). Save the game next to the holovator that brings you to the roof where Latios spawns, then toggle the macro.

> [!CAUTION]
> Please be aware that this macro closes the game; use with caution.

----
